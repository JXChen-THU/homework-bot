# 作业清单 v26.6

一个面向 Windows 10/11 的桌面作业汇总工具。它通过浏览器会话读取已配置学习平台的任务，
并把任务集中显示在主面板和桌面浮窗中。

**v26.6 重点在三件事**：① 第一次运行不再空等（没有任何登录状态就不抓，直接显示窗口引导你填账号密码）；
② 「静默启动」改回默认关 —— 是否静默该由你自己选；③ 抓取失败不再停在报错上，
而是自动清会话、静默重登，最多连续 3 次（密码明确错时立刻提示，不反复登录）。

---

## 功能

- 汇总多个学习平台的作业和考试，并显示课程、截止时间及链接。
- 将任务分为未完成和已完成；勾选后可随时撤销。
- 自动把 24 小时内截止的任务、以及**所有已过期**的未完成任务放入红色紧急浮窗
  （过期多久都算紧急），其余未完成任务放入白色提醒浮窗。
- 支持在浮窗中直接标记任务完成，也可以添加和删除手动任务。
- **填好账号密码后自动后台登录**：登录状态失效时程序静默重登，不需要手动操作。
- **登录失败会说清原因**：密码错、还需要一次验证码、平台不支持自动登录、网络/接口故障，
  四种情况给出不同话术和不同按钮，不会一律显示"登录未完成"。
- **抓取报错会自动重登（v26.6）**：任何抓取失败（服务端 500、页面改版、超时…）都会立刻
  用你填过的账号密码**静默重登**再抓，最多**连续 3 次**；其中"超时"会先清掉该站点的登录记录。
  只有重登也不管用、或这台机器上没有可用账密（平台只能扫码 / 换了电脑解不开密文）时，
  才会提示"需要登录"或报错。接口 5xx / 页面改版**不会**清你的登录记录。
- **密码填错立刻提示（v26.6）**：平台明确回"用户名或密码不正确"时当场停下，直接显示
  「自动登录失败，账号或密码可能不对」，并进入 30 分钟冷却（期间刷新不会再撞平台）。
- 可在设置中启用或停用站点、填写账号密码、清除会话、删除站点；Tyche 另外支持配置 Basic Auth 账号密码。
- **第一次运行不会空等（v26.6）**：一个登录会话都没有、也还没填账号密码时，那一轮
  **不发任何网络请求、不启动浏览器**，直接显示窗口并给出一条引导（列出要配置的站点）。
- 支持 Windows 开机自启动；启动后的首轮抓取会先等网络就绪。
- **抓取时有进度文字区**：显示正在检查网络、哪个站点开始抓取、抓到了几条；
  最多 3 行、逐行滚动，抓完自动收起并把空间还给任务列表。
- **启动行为可选**：设置里可以选「静默抓取」（每次启动都不出现窗口）或「直接显示界面」。
  **出厂默认是直接显示界面**（见下文「启动与第一次运行」）。
- **界面外观可选三态（v26.5）**：跟随系统 / 浅色 / 深色，三个窗口实时同步。

| 清华 OJ | 作业 | 清华统一身份认证 | 全自动（屏幕外窗口） |

| 雨课堂 | 作业、考试、试卷 | 微信扫码 | 不支持，需手动扫码 |

### 自动登录是怎么工作的

在设置里给站点填好账号密码后，抓取时如果发现登录状态失效，程序会自动**分两层**尝试，
全程不需要你操作：

1. **无头浏览器**静默登录（一般站点的正常路径：Tyche / 数你最灵 / U 校园）。
2. **屏幕外窗口**：如果站点会挑战无头浏览器（清华 SSO 就是这样），程序改用**真实窗口**，
   但把窗口放到屏幕坐标之外，登录完成后立即关闭。
3. 两层都失败（例如确实需要你手工输入短信验证码）才会提示你处理；点「登录」后
   窗口里的账号密码**已经自动填好**，你通常只需要输入验证码。

> 关于屏幕外窗口：它终究是一个真实窗口，所以**任务栏上可能短暂出现一个图标**。
> 它不会出现在屏幕可见区域，也不会抢焦点，登录完成后自动关闭。
> 之所以不改成「最小化」，是因为窗口必须先创建出来才能最小化，创建那一瞬间仍会在屏幕中间
> 闪一下；而屏幕外位置是在窗口创建时就指定的，从头到尾不会出现在你眼前。

关于清华的两个平台（网络学堂、清华 OJ）：它们都走清华统一身份认证（SSO）。

- 会话**还有效**时：直接复用会话，几秒完成，不触发 SSO。
- 会话**失效**时：SSO 会拦无头浏览器、要求二次验证，但放行真实窗口。实测屏幕外真实窗口
  可以直接登录成功，因此这两个平台也能全自动，前提是你的账号当时没有额外触发短信验证。
- 因为无头在这两个站是**必定**失败的，程序会直接跳过无头那一档，省掉一次注定失败的登录。

为避免反复去撞 SSO，某个站点后台登录失败后会有冷却时间（需要验证码的等 10 分钟，
账号密码错误的等 30 分钟），期间不再自动重试。在设置里重新填写账号密码会**立即清掉该站点的冷却**。

## 抓取失败时会发生什么（v26.6）

这是 v26.6 变化最大的一块，规则如下：

| 失败类型 | 是否清登录记录 | 之后 |
|---|---|---|
| 页面跳到登录页 / 接口回 401、403 | 不清 | 静默重登；登不回来则提示「需要登录」 |
| 会话文件损坏 | 清（自愈） | 静默重登；登不回来则提示「需要登录」 |
| **超时**（等满 5 秒没内容、又没有任何失效信号） | **清** | 静默重登；仍失败则报「抓取超时」 |
| 接口 5xx / 页面改版 / 浏览器崩溃 | 只在"确定要重登"时清（见下） | **也重登**；仍失败则照实报错 |
| **平台明确回"密码不正确"** | — | **立刻停下并提示**，不重复登录，30 分钟内不再自动尝试 |

- 一次刷新里最多**连续重登 3 次**（即最多 4 次抓取）。上限是必需的：如果平台一直 5xx，
  "报错 → 重登 → 再报错"会无限转下去，一次刷新就卡死。
- 决定重登时会先**丢掉那份刚刚抓取失败的登录记录**，逼这一轮做一次真实登录。
  这条很关键：旧会话留着的话，程序会先拿它去试，只要首页还能打开就以为"重登成功"，
  于是反复空转（旧版本实测会白转三轮、几十秒，密码错也判不出来）。
- 但只有"确定登得回来"才会丢：平台不支持账密登录（雨课堂只能扫码）、没填账密、
  密文在这台机器上解不开（换了电脑）、或该站点还在失败冷却期内 —— 这些情况下
  既不丢会话也不发起登录。
- 平台对"密码错"是有明确信号的，所以程序不需要靠"再试一次"确认；收到就当场把这句话说出来。

**实际要等多久**（本机实测，网络学堂、故意填错密码）：

| 阶段 | 耗时 |
|---|---|
| 抓取（会话预检 1 秒 + 数据等待 5 秒） | 约 6.5 秒 |
| 真实重登：其中**判定出"密码错"只用了 2.1 秒**，其余约 6.5 秒是浏览器（Playwright）退出的固定开销 | 约 8.6 秒 |
| **首次刷新合计** | **约 15 秒** |
| 之后再刷新（30 分钟冷却期内，不再发起登录） | **0 秒**（直接给提示） |

登录流程里的固定等待也已改成"表单一出现就走"：原来网络学堂要白等 2.5+4 秒、
U 校园要白等 4+6 秒，现在只在页面真的慢时才等那么久。

## 界面与主题（v26.5 重做，v26.6 沿用）

v26.5 重做了整套界面样式，有三件事值得知道：

- **三个窗口共用一份主题表**。主窗口、红色紧急浮窗、白色提醒浮窗是三个独立文档，
  以前同一套颜色变量在三个文件里各写一遍，改一处要同步三处（也因此长期存在
  "浮窗里某个颜色解析成空值"的问题）。现在统一放在 `web/theme-shared.css`，
  三个页面各自在**自己的样式表之前**引入它。
- **浅色 / 深色 / 跟随系统**三态，设置面板「外观」里切换。三个窗口通过
  `localStorage` + `storage` 事件实时同步，不需要重启。
- **界面用系统字体**：拉丁 `Times New Roman` + 中文`楷体`（KaiTi），离线可用、不发网络请求；
  表单控件（按钮/输入框）强制继承同一套字体，不再出现"按钮是 Arial"的混搭。
  仓库与安装包都**不再分发字体文件**（原来随包的 3 个 `.ttf` 是商业字体，已移除）；
  机器上没有楷体时，按 `华文楷体` → `Microsoft YaHei` → 通用 serif 依次兜底。

浮窗一次显示的条数上限：红色 8 条、白色 12 条，超出会显示「…还有 N 条」。

## 启动与第一次运行（v26.6）

**启动行为**（设置里的两个开关，改完立即保存到 `sites.yaml` 的 `startup_mode`，下次启动生效）：

- `开机自启动`：开启后每次开机并联网自动启动。
- `启动时静默`：**开启**时每次启动都不出现窗口，只在后台把任务抓好，需要看任务时点浮窗
  的「主面板」；**关闭**则启动就出现窗口，能直接看到抓取进度文字区逐行滚动。
  **这个开关出厂是关闭的** —— 是否静默该由你自己选，程序不会替一个还没选过的人默认选上。
  （旧版本留下的 `sites.yaml` 里如果已经有这个设置，升级后仍按你的设置走；没有这个键时，
  已经有会话文件的按"静默"沿用旧行为，全新机器才默认显示界面。）

**第一次运行（一个登录会话都没有、也还没填账号密码）**：

程序**不会**去抓作业 —— 那一轮的结果必然是"需要登录"，代价却是最多 120 秒网络等待
加上每个站点各拉起一次浏览器，这就是以前"双击之后很久什么都没发生"的原因。现在的行为是：

1. 立即显示主窗口（即使启动行为设成静默也一样：此时你还没有登录状态，必须看得见入口）；
2. 顶部给出一条引导，列出要配置的站点，点站点按钮即可**填账号密码**；
3. 填完（或点「添加任务」手动记一条）之后一切照旧：正常登录、正常抓取、正常刷新。

只要你填过任意一个站点，或者任意一个站点已有会话文件，下次启动就回到正常抓取流程。

浮窗会在任务刷新或任务状态改变时更新，不会按固定间隔主动抓取（它每秒只问一次主窗口是否可见，
用来切换"主面板 / 收起"按钮状态）。

## 运行

### 使用打包版

解压程序文件夹后运行 `HomeworkTasks.exe`（`_internal\` 必须与它放在一起）。
首次启动会根据 `sites.yaml.template` 生成 `sites.yaml`，并创建 `data/` 运行数据目录；
首次使用时在设置里配置需要的站点并登录。

打包产物里只有程序本身（页面、样式、脚本、平台适配器、浏览器驱动），
**不包含**你的 `sites.yaml`、`data/`、日志或备份文件；字体也不在包里（界面直接用系统字体）。

### 从源码运行

需要 Windows、Python 3.10 或更新版本（开发与验证环境为 3.12），以及已安装的 Microsoft Edge：

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirement.txt
.\.venv\Scripts\python.exe app.py
```

`start.bat` 用于源码模式下的开机启动：它会优先使用项目里的 `.venv\Scripts\pythonw.exe`，
找不到才退回系统 Python。运行抓取时会通过 Playwright 调用本机 Microsoft Edge。

### 打包

仓库**不再附带 PyInstaller 配方**（`HomeworkTasks.spec` 已按需求移除）。需要打包时安装
PyInstaller，在项目目录运行这条等价命令：

```powershell
.\.venv\Scripts\python.exe -m pip install pyinstaller
.\.venv\Scripts\python.exe -m PyInstaller --noconsole --name HomeworkTasks `
  --icon icon.ico --add-data "web;web" --add-data "sites.yaml.template;." `
  --collect-all playwright app.py
```

结果位于 `dist/HomeworkTasks/`。它只收集 `web/`、`sites.yaml.template` 与 playwright 运行时
（界面用**系统字体**，所以没有字体相关的 `--add-data`）。

⚠️ 发布前请确认分享包里没有你自己的 `sites.yaml` 或 `data/` —— **运行过一次产物里的 exe 后，
它会在产物目录里就地生成这两项，压缩分享前要先删掉。**

## 首次配置

1. 启动后打开「设置」，启用需要的平台。
2. 给需要的站点点「填账号密码」：
   - 数你最灵还要填「学校全名」（例如 `XX大学`），登录前必须先选学校。
   - Tyche 有两组账号密码：**Basic Auth** 是打开网站时浏览器弹窗用的，**网站账号密码**是
     网站内部的登录，两组都要填。
   - 雨课堂只能微信扫码，不需要填账号密码。
3. 清华的系统（网络学堂、清华 OJ）会自动尝试后台登录；如果弹出浏览器窗口，说明需要你输入
   一次验证码，窗口里账号密码已自动填好。
4. 如需开机启动，在设置中打开对应开关。
5. 想要深色界面，在「外观」里选「深色」或「跟随系统」。

## 日常操作

- **刷新任务**：重新访问启用的平台；抓取期间保留当前列表，完成后更新结果。多个平台是**同时**
  抓取的（默认 3 个并发），总耗时约等于最慢的那个；可用环境变量 `HOMEWORK_BOT_WORKERS` 调整
  （例如设为 `1` 退回串行）。
- **自动重登**：登录状态失效时自动完成，无需操作；只有需要验证码时才会提示你。
- **添加/完成任务**：添加自己的事项（标题、截止时间必填，课程和链接可选）；
  在主面板或浮窗勾选完成，可随时撤销。
- **管理站点**：设置中的开关、清除登录、删除等更改需要点「应用」后生效。
- **填账号密码**：改完会清掉该站点的旧会话与自动重登冷却，下次刷新用新账号重新登录。
- **控制浮窗**：标题栏的「主面板」切换主窗口；「—」最小化该浮窗；「×」关闭该浮窗。
  主面板的「重置浮窗」可重新显示被关闭或最小化的浮窗。
- **退出程序**：关闭主窗口会退出程序并关闭浮窗；单独关闭浮窗不会退出主程序。

## 本地数据与隐私

程序默认把数据放在项目目录（打包版为 exe 同级目录）。如果这个位置不可写（例如解压到
`Program Files`），会改用 `%LOCALAPPDATA%\HomeworkTasks`，并尽量把原有的 `sites.yaml` 与
`data/` 复制过去；界面上会有横幅说明实际使用的目录。

生成的文件：

- `sites.yaml`：站点启用状态和配置；账号密码（含 Tyche 的 Basic Auth 凭据）**加密后**保存在此文件。
- `data/homework.db`：手动任务和完成状态。
- `data/*_session.json`：各平台的登录会话。
- `data/*_courses.json`：部分平台的课程缓存。

这些文件可能包含账号凭据、登录状态或个人任务。不要把它们发送给他人或提交到公开仓库。
备份个人设置时可单独备份 `sites.yaml` 和 `data/`；分享程序时则应排除它们。仓库的 `.gitignore`
已忽略 `sites.yaml`、`*.bak`、`data/`、`*.db`、`*_session.json`、`*_courses.json`。

### 账号密码是怎么加密的

`sites.yaml` 里的账号和密码用 **Windows 自带的 DPAPI** 加密，存储成 `enc:v1:...` 形式。
密钥由 Windows 按当前登录账户托管，所以：

- 程序能自己解开 → **不影响开机后台自动抓取**，你不用输入任何额外密码
- 换一台电脑、或换成另一个 Windows 账户，这些密文**解不开**（这是特性，不是 bug）；
  程序会把该站点显示为「密码需重填」，在设置里重新填一次即可
- 旧版本留下的明文账号密码，会在**首次启动时自动加密**；如果这一步失败，界面会明确提示
  "磁盘上可能仍是明文"，而不是静默假装成功

需要说清楚的边界：**这挡的是「文件被别人看到」**（误传网盘、被同步工具上传、误提交进仓库），
**不是「防住本机恶意软件」**——任何以你的身份运行的程序都能调用 DPAPI 解密。

## 常见问题

**提示需要登录或抓取失败怎么办？** 提示条会写明具体原因：需要验证码就点「去验证」；
账号密码可能不对就点「重新填账号密码」；网络或平台接口故障则稍后刷新重试。
仍不行时，在设置中清除对应平台的登录状态并重新登录。

**红色浮窗没有显示？** 没有 24 小时内截止、也没有已过期的未完成任务时，红色浮窗会隐藏。
**过期多久都算紧急**（v26.6 按需求取消了早先"过期超过 3 天降级到白窗"的下限），
所以红窗里出现几个月前就该交的作业是**预期行为** —— 它按"过期越久越靠前"排序，一次最多 8 条。

**开机后没有任务？** 程序启动后的**首轮**抓取最多等待网络 120 秒（之后的「刷新任务」不再等待），
网络恢复后可点「刷新任务」重试。如果一个登录会话都没有（第一次运行、或删过 `data/`），
启动那轮**根本不会去抓**，而是直接显示界面让你先填账号密码 —— 见上文「启动与第一次运行」。

**为什么现在等得没以前久了？** 会话失效时浏览器是被平台直接跳到登录页的，程序现在
**一看到登录页就立刻结束等待**（预检上限 1 秒），而不是像以前那样空等 15 秒；等作业数据
回来最多给 5 秒。**万一抓取出错了（含超时），程序会自动重登再抓**：最多连续重登 3 次，
决定重登时会先丢掉那份刚判失败的旧会话（逼一次真实登录）；没账密 / 平台不支持 / 账密解不开 /
冷却期内则既不丢也不登。连续 3 次都不行时才会提示"需要登录"或报错。如果是**账号密码本身不对**，程序在第一次尝试后就停下，直接提示
「自动登录失败，账号或密码可能不对，请点按钮重新填写」，并进入 30 分钟冷却
（首次约 15 秒内给出，之后刷新立即提示）。
（每次抓取固定还有约 7 秒的浏览器启动/退出开销，与网络无关，属于另一件事。）

**如何清空任务和登录状态？** 退出程序后，删除 `data/` 可清除数据库、会话和缓存；
删除 `sites.yaml` 会在下次启动时重新生成默认站点配置。

**界面颜色不对 / 想只看深色？** 设置面板「外观」里可以选跟随系统、浅色或深色，三个窗口会同时切换。
