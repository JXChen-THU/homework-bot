# 任务清单

一个把多个学习平台的作业汇总到桌面上的小工具。

支持 Windows 10/11。登录一次后自动抓取、自动提醒，不用反复操作。

---

## 功能

- 📚 **多平台汇总**：清华 OJ、网络学堂、雨课堂、Tyche 四个平台的作业集中显示
- ✅ **完成分栏**：未完成 / 已完成两个标签页，勾选后自动沉底
- ⏰ **红白浮窗**：桌面右上角常驻
  - 红色浮窗：24 小时内截止或已过期的任务
  - 白色浮窗：其他未完成任务
- ➕ **手动任务**：可以添加任意自己的任务，比如"复习期末考试"
- 🚀 **开机自启动**：在设置里一键开启，开机后主面板最小化到任务栏，不打扰
- 🌐 **联网检测**：开机时如果还没联网，会先等待联网再抓取，不会报错
- 🎨 **不打扰**：主窗口可关闭，浮窗保留，随时点浮窗的"主面板"唤回

---

## 安装

1. 解压到任意位置（例如桌面）
2. 双击 `任务清单.exe`
3. 第一次启动会在同目录自动生成 `sites.yaml`（站点配置）
4. 完成后看下面"使用"章节

> ⚠️ **如果 360 / 火绒 / 电脑管家报毒**
>
> 这是打包程序的**普遍误报**，不是病毒。
> 请把整个文件夹添加到杀毒软件的**信任区 / 白名单**。
> 想验证可以上传 `任务清单.exe` 到 https://www.virustotal.com/ 扫描。

> ⚠️ **不要把程序放在 C 盘 Program Files 之类的目录**
>
> 那些目录需要管理员权限，程序无法在里面生成配置文件和数据库。
> 放在桌面、文档、D 盘都可以。

## 使用

### 第一次使用

1. **填 Tyche 账号密码**（如果要用 Tyche）
   - 打开设置 → 找到"Tyche"→ 点"填账号密码"
   - 填的是**打开 Tyche 网站时浏览器弹出的第一个登录框**的账号密码
   - 不是网站内部的账号密码

2. **登录各平台**
   - 主界面顶部会出现"需要登录以下站点"
   - 逐个点"登录"按钮，会弹出浏览器
     - 清华 OJ / 网络学堂：清华统一身份认证
     - 雨课堂：微信扫码
     - Tyche：Basic Auth（已填的账号密码）+ 网站内部登录
   - 登录成功后浏览器自动关闭，作业出现

3. **开启开机自启动**（可选）
   - 设置 → 打开"开机自动启动"开关
   - 之后每次开机并联网后自动启动，主面板最小化到任务栏

### 日常使用

- **添加任务**：右上角"添加任务"
- **刷新**：右上角"刷新任务"，重新抓取各平台
- **勾选完成**：直接点左边的复选框
- **删除手动任务**：鼠标悬停在任务上，右边出现"删除"按钮
- **关闭主窗口**：点右上角 X，主窗口从任务栏消失，程序继续后台运行，红白浮窗保留
- **唤回主窗口**：点红窗或白窗的"主面板"按钮

### 浮窗操作

红白浮窗标题栏右侧有三个按钮：

| 按钮 | 作用 |
|---|---|
| 主面板 | 主面板显示时点→隐藏；未显示时点→显示 |
| 最小化 | 把浮窗缩到任务栏 |
| × | 关闭这个浮窗，不再自动弹出 |

浮窗不会自动刷新，只在**点"刷新任务"**或**勾选任务**时更新，不会主动打扰。

### 退出程序

- 红白浮窗都被 `×` 掉后，点主面板 `×` → 程序彻底退出
- 只要还有浮窗在显示，主面板 `×` 只是最小化到任务栏

### 设置

右上角"设置"分两个区块：

**🌐 网站设置**

| 操作 | 说明 |
|---|---|
| 开关 | 启用/禁用某个平台 |
| 填账号密码 | 仅 Tyche 需要，填 Basic Auth 的账号密码 |
| 清除登录 | 清除该平台的登录状态，下次需重新登录 |
| 删除 | 彻底移除该平台配置 |

> 修改后需要点右下角 **"应用"** 才生效。点"应用"前可以随时撤销改动。

**🚀 开机自启动**

一个开关，打开后每次开机自动运行。

## 目录结构

任务清单文件夹里会有这些东西：

- `任务清单.exe` — 主程序
- `_internal\` — 依赖库，**不要删除**
- `sites.yaml` — 站点配置（首次启动自动生成）
- `data\` — 数据目录（自动生成）
  - `*_session.json` — 各平台登录凭证
  - `homework.db` — 任务记录数据库
  - `*_courses.json` — 课程列表缓存

## 常见问题

**Q: 会不会窃取我的隐私？**

A: 不会。这个软件没有服务器后端，作者也收不到你的任何数据。它本质上只是一个本地小程序：

- **没有服务器**：作者没有搭任何后端接收数据，想偷也偷不到
- **全部本地存储**：账号密码、登录凭证、任务记录，都只写在你自己电脑的程序文件夹里
- **不联网上传**：除了访问你登录的四个平台官网拉取作业，不向任何地方发送数据
- **没有埋点、没有统计、没有云端同步**

**Q: 开机自启动显示登入网站错误？**

A: 连网的速度比抓取的速度慢。程序现在会在抓取前自动等待网络就绪（最多 120 秒），如果确实没网会显示"等待网络连接超时"，联网后点"刷新任务"即可。

**Q: 双击 exe 没反应？**

A: 检查是否有杀毒软件拦截，加入白名单后重试。也可能是 `_internal\` 文件夹丢失。

**Q: 提示"需要登录"但登录失败？**

A: 会话过期。点设置 → 清除登录 → 重新点登录走一遍流程。

**Q: 红窗不显示？**

A: 只在有 24 小时内截止或已过期的任务时显示。没有紧急任务时红窗是隐藏的，这是正常的。

**Q: 抓不到某个平台的作业？**

A1. 该平台可能没有作业（比如体育课）
A2. 该平台会话过期，去设置里重新登录
A3. 网站改版了，需要更新对应的适配器

**Q: 主面板点 X 后任务栏按钮不见了？**

A: 正常行为。主面板 X 会彻底隐藏（从任务栏消失），程序还在后台跑，浮窗还在。想唤回主面板，点浮窗的"主面板"按钮。

**Q: 点浮窗的 × 关掉后怎么恢复？**

A: 关掉的浮窗不会自动再弹出来。想恢复的话重启程序即可。或者主面板刷新任务时，如果任务还在，浮窗也不会自动弹出（这是设计如此，避免打扰）。

**Q: 开机自启动不生效？**

A: 到设置里关掉再打开一次，或者打开注册表编辑器检查：
`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` 里应该有 `HomeworkTasks`。

**Q: 数据存在哪？**

A: 全在程序同目录。删掉 `data\homework.db` 会清空所有任务记录（但登录凭证还在），删掉 `data\` 整个目录会清空所有数据。

## 卸载

1. 设置里关闭"开机自启动"
2. 如果任务管理器里还有 `任务清单.exe` 在跑，结束它
3. 直接删除整个文件夹
4. 如果想彻底清理注册表，删除：
   `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run\HomeworkTasks`
