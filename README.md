# 作业清单 v26.3

一个面向 Windows 10/11 的桌面作业汇总工具。它通过浏览器会话读取已配置学习平台的任务，并把任务集中显示在主面板和桌面浮窗中。

## 功能

- 汇总多个学习平台的作业和考试，并显示课程、截止时间及链接。
- 将任务分为未完成和已完成；勾选后可随时撤销。
- 自动把 24 小时内截止及已过期任务放入红色紧急浮窗，其余未完成任务放入白色提醒浮窗。
- 支持在浮窗中直接标记任务完成，也可以添加和删除手动任务。
- **填好账号密码后自动后台登录**：登录状态失效时程序静默重登，不需要手动操作。
- 可在设置中启用或停用站点、填写账号密码、清除会话、删除站点；Tyche 另外支持配置 Basic Auth 账号密码。
- 支持 Windows 开机自启动；启动时会等待网络就绪后再抓取。

## 支持的平台

| 平台 | 当前抓取内容 | 登录方式 | 自动后台登录 |
|---|---|---|---|
| 清华 OJ | 作业 | 清华统一身份认证 | 全自动（屏幕外窗口） |
| 网络学堂 | 作业 | 清华统一身份认证 | 全自动（屏幕外窗口） |
| 雨课堂 | 作业、考试、试卷 | 微信扫码 | 不支持，需手动扫码 |
| Tyche | 作业 | Basic Auth + 网站登录 | 完全自动 |
| 数你最灵 | 作业 | 学校 + 学号/工号 + 密码 | 完全自动 |
| U 校园 | 考试 | 手机号/邮箱 + 密码 | 完全自动 |

U 校园当前只抓取考试列表；其他类型暂未接入。

### 自动登录是怎么工作的

在设置里给站点填好账号密码后，抓取时如果发现登录状态失效，
程序会自动**分三层**尝试，全程不需要你操作：

1. **无头浏览器**静默登录（一般站点的正常路径，Tyche / 数你最灵 / U校园 走这里）。
2. **屏幕外窗口**：如果站点会挑战无头浏览器（清华 SSO 就是这样），
   程序改用**真实窗口**，但把窗口放到屏幕坐标之外，登录完成后立即关闭。
3. 前两层都失败（例如确实需要你手工输入短信验证码）才会提示你处理，
   点「登录」后窗口里的账号密码**已经自动填好**，你通常只需要输入验证码。

> 关于屏幕外窗口：它终究是一个真实窗口，所以**任务栏上可能短暂出现一个图标**。
> 它不会出现在屏幕可见区域，也不会抢焦点，登录完成后自动关闭。
> 之所以不改成「最小化」，是因为窗口必须先创建出来才能最小化，
> 创建那一瞬间仍会在屏幕中间闪一下；而屏幕外位置是在窗口创建时就指定的，
> 从头到尾不会出现在你眼前。

关于清华的两个平台（网络学堂、清华 OJ）：它们都走清华统一身份认证（SSO）。

- 会话**还有效**时：直接复用会话，几秒完成，不触发 SSO。
- 会话**失效**时：SSO 会拦无头浏览器、要求二次验证，但放行真实窗口。
  实测屏幕外真实窗口可以直接登录成功，因此这两个平台也能全自动，
  前提是你的账号当时没有额外触发短信验证。
- 因为无头在这两个站是**必定**失败的，程序会直接跳过无头那一档，
  省掉一次注定失败的登录和一次多余的 SSO 交互。

为避免反复去撞 SSO，某个站点后台登录失败后会有冷却时间
（需要验证码的等 10 分钟，账号密码错误的等 30 分钟），期间不再自动重试。


## 运行

### 使用打包版

解压程序文件夹后运行 `HomeworkTasks.exe`。首次启动会根据 `sites.yaml.template` 生成 `sites.yaml`，并创建 `data/` 运行数据目录。首次使用时，在设置中配置需要的站点并登录。

### 从源码运行

需要 Windows、Python 3.10 或更新版本，以及已安装的 Microsoft Edge。打开项目目录后执行：

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirement.txt
.\.venv\Scripts\python.exe app.py
```

`start.bat` 用于源码模式下的开机启动。运行抓取时会通过 Playwright 调用本机 Microsoft Edge。

### 打包

安装 PyInstaller 后，在项目目录运行：

```powershell
.\.venv\Scripts\python.exe -m pip install pyinstaller
.\.venv\Scripts\pyinstaller.exe HomeworkTasks.spec
```

打包结果位于 `dist/HomeworkTasks/`。发布前不要把自己的 `sites.yaml` 或 `data/` 放进分享包。

## 首次配置

1. 启动后打开“设置”，启用需要的平台。
2. 给需要的站点点「填账号密码」，填入账号和密码。填好后，登录状态失效时程序会自动后台重登。
   - 数你最灵还要填「学校全名」（例如 `XX大学`），登录前必须先选学校。
   - Tyche 有两组账号密码：**Basic Auth** 是打开网站时浏览器弹窗用的，**网站账号密码**是网站内部的登录，两组都要填。
   - 雨课堂只能微信扫码，不需要填账号密码。
3. 清华的系统（网络学堂、清华 OJ）会自动尝试后台登录；如果弹出浏览器窗口，说明需要你输入一次验证码，窗口里账号密码已自动填好。
4. 如需开机启动，在设置中打开对应开关。

## 日常操作

- **刷新任务**：重新访问启用的平台；抓取期间保留当前列表，完成后更新结果。
  多个平台是**同时**抓取的（默认 3 个并发），因此总耗时约等于最慢的那个平台。
  如需调整并发数，可设置环境变量 `HOMEWORK_BOT_WORKERS`（例如设为 `1` 退回串行）。
- **自动重登**：登录状态失效时自动完成，无需操作；只有需要验证码时才会提示你。
- **添加任务**：添加自己的事项，填写标题和截止时间，课程和链接可选。
- **完成任务**：在主面板或浮窗勾选；已完成任务会进入“已完成”标签。
- **管理站点**：设置中的开关、清除登录、删除等更改需要点“应用”后生效。
- **填账号密码**：改完账号密码会清掉该站点的旧会话，下次刷新用新账号重新登录。
- **控制浮窗**：标题栏的“主面板”按钮切换主窗口；“—”最小化该浮窗；“×”关闭该浮窗。主面板的“重置浮窗”可重新显示关闭或最小化的浮窗。
- **退出程序**：关闭主窗口会退出程序并关闭浮窗。单独关闭浮窗不会退出主程序。

浮窗会在任务刷新或任务状态改变时更新，不会按固定间隔主动抓取。

## 项目结构

```text
app.py                  桌面程序入口
core/
  controller.py         窗口协调和前端 API
  database.py           SQLite 持久化
  site_runner.py         站点配置、网络等待和抓取调度
  task_logic.py          截止时间解析和任务分类
adapters/               各学习平台的登录、抓取和解析
web/                    HTML、CSS 和 JavaScript
sites.yaml.template     首次启动使用的站点配置模板
data/                   运行时生成的数据目录
```

## 本地数据与隐私

程序会在项目目录（打包版为 exe 同级目录）生成以下文件：

- `sites.yaml`：站点启用状态和配置；账号密码（含 Tyche 的 Basic Auth 凭据）**加密后**保存在此文件。
- `data/homework.db`：手动任务和完成状态。
- `data/*_session.json`：各平台的登录会话。
- `data/*_courses.json`：部分平台的课程缓存。

这些文件可能包含账号凭据、登录状态或个人任务。不要把它们发送给他人或提交到公开仓库。备份个人设置时，可单独备份 `sites.yaml` 和 `data/`；分享程序时则应排除它们。

### 账号密码是怎么加密的

`sites.yaml` 里的账号和密码用 **Windows 自带的 DPAPI** 加密，存储成 `enc:v1:...` 形式。
密钥由 Windows 按当前登录账户托管，所以：

- 程序能自己解开 → **不影响开机后台自动抓取**，你不用输入任何额外密码
- 换一台电脑、或换成另一个 Windows 账户，这些密文**解不开**（这是特性，不是 bug）；
  程序会把该站点显示为「密码需重填」，在设置里重新填一次即可
- 旧版本留下的明文账号密码，会在**首次启动时自动加密**，你不需要做任何操作

需要说清楚的边界：**这挡的是「文件被别人看到」**（误传网盘、被同步工具上传、
误提交进仓库），**不是「防住本机恶意软件」**——任何以你的身份运行的程序
都能调用 DPAPI 解密。真想改配置时，在程序的「设置 → 填账号密码」里改就行。

## 常见问题

**提示需要登录或抓取失败怎么办？** 先检查网络，再在设置中清除对应平台的登录状态并重新登录。网站接口或页面变动时，也可能需要更新对应适配器。

**红色浮窗没有显示？** 没有 24 小时内截止或已过期的未完成任务时，红色浮窗会隐藏。

**开机后没有任务？** 程序启动时最多等待网络 120 秒。网络恢复后可点“刷新任务”重试。

**如何清空任务和登录状态？** 退出程序后，删除 `data/` 可清除数据库、会话和缓存；删除 `sites.yaml` 会在下次启动时重新生成默认站点配置。
