# 作业清单 v26.3

一个面向 Windows 10/11 的桌面作业汇总工具。它通过浏览器会话读取已配置学习平台的任务，并把任务集中显示在主面板和桌面浮窗中。

## 功能

- 汇总多个学习平台的作业和考试，并显示课程、截止时间及链接。
- 将任务分为未完成和已完成；勾选后可随时撤销。
- 自动把 24 小时内截止及已过期任务放入红色紧急浮窗，其余未完成任务放入白色提醒浮窗。
- 支持在浮窗中直接标记任务完成，也可以添加和删除手动任务。
- 可在设置中启用或停用站点、重新登录、清除会话；Tyche 支持配置 Basic Auth 账号密码。
- 支持 Windows 开机自启动；启动时会等待网络就绪后再抓取。

## 运行

### 使用打包版

解压程序文件夹后运行 `HomeworkTasks.exe`。首次启动会根据 `sites.yaml.template` 生成 `sites.yaml`，并创建 `data/` 运行数据目录。首次使用时，在设置中配置需要的站点并登录。

### 从源码运行

需要 Windows、Python 3.10 或更新版本，以及已安装的 Microsoft Edge。打开项目目录后执行：

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirement.txt
.\.venv\Scripts\python.exe app.py
```

`start.bat` 用于源码模式下的开机启动。运行抓取时会通过 Playwright 调用本机 Microsoft Edge。

### 打包

安装 PyInstaller 后，在项目目录运行：

```powershell
.\.venv\Scripts\python.exe -m pip install pyinstaller
.\.venv\Scripts\pyinstaller.exe HomeworkTasks.spec
```

打包结果位于 `dist/HomeworkTasks/`。发布前不要把自己的 `sites.yaml` 或 `data/` 放进分享包。

## 首次配置

1. 启动后打开“设置”，启用需要的平台。
2. 如果使用 Tyche，先填写打开站点时浏览器 Basic Auth 弹窗所需的账号密码。
3. 在主面板顶部的登录提示中逐个平台登录。登录成功后，会话保存在本地，后续刷新可复用。
4. 如需开机启动，在设置中打开对应开关。

## 日常操作

- **刷新任务**：重新访问启用的平台；抓取期间保留当前列表，完成后更新结果。
- **添加任务**：添加自己的事项，填写标题和截止时间，课程和链接可选。
- **完成任务**：在主面板或浮窗勾选；已完成任务会进入“已完成”标签。
- **管理站点**：设置中的开关、清除登录、删除等更改需要点“应用”后生效。
- **控制浮窗**：标题栏的“主面板”按钮切换主窗口；“—”最小化该浮窗；“×”关闭该浮窗。主面板的“重置浮窗”可重新显示关闭或最小化的浮窗。
- **退出程序**：关闭主窗口会退出程序并关闭浮窗。单独关闭浮窗不会退出主程序。

浮窗会在任务刷新或任务状态改变时更新，不会按固定间隔主动抓取。

## 项目结构

```text
app.py                  桌面程序入口
core/
  controller.py         窗口协调和前端 API
  database.py           SQLite 持久化
  site_runner.py         站点配置、网络等待和抓取调度
  task_logic.py          截止时间解析和任务分类
adapters/               各学习平台的登录、抓取和解析
web/                    HTML、CSS 和 JavaScript
sites.yaml.template     首次启动使用的站点配置模板
data/                   运行时生成的数据目录
```

## 本地数据与隐私

程序会在项目目录（打包版为 exe 同级目录）生成以下文件：

- `sites.yaml`：站点启用状态和配置；Tyche 的 Basic Auth 凭据保存在此文件。
- `data/homework.db`：手动任务和完成状态。
- `data/*_session.json`：各平台的登录会话。
- `data/*_courses.json`：部分平台的课程缓存。

这些文件可能包含账号凭据、登录状态或个人任务。不要把它们发送给他人或提交到公开仓库。备份个人设置时，可单独备份 `sites.yaml` 和 `data/`；分享程序时则应排除它们。

## 常见问题

**提示需要登录或抓取失败怎么办？** 先检查网络，再在设置中清除对应平台的登录状态并重新登录。网站接口或页面变动时，也可能需要更新对应适配器。

**红色浮窗没有显示？** 没有 24 小时内截止或已过期的未完成任务时，红色浮窗会隐藏。

**开机后没有任务？** 程序启动时最多等待网络 120 秒。网络恢复后可点“刷新任务”重试。

**如何清空任务和登录状态？** 退出程序后，删除 `data/` 可清除数据库、会话和缓存；删除 `sites.yaml` 会在下次启动时重新生成默认站点配置。
