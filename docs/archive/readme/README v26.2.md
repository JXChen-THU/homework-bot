# 任务清单 v26.2

一个把多个学习平台的作业汇总到桌面上的小工具。

支持 Windows 10/11。登录一次后自动抓取、自动提醒，不用反复操作。

## ✨ 功能

- 📚 **多平台汇总**：清华 OJ、网络学堂、雨课堂、Tyche、数你最灵、U校园 六个平台集中显示
- ✅ **完成分栏**：未完成 / 已完成两个标签页，勾选后自动沉底
- ⏰ **红白浮窗**：桌面右上角常驻
  - 红色浮窗：24 小时内截止或已过期的任务
  - 白色浮窗：其他未完成任务
  - 可在浮窗上直接勾选完成
  - 支持**最小化到任务栏**和**关闭**
- ➕ **手动任务**：可以添加任意自己的任务，比如"复习期末考试"
- 🚀 **开机自启动**：设置里一键开启
- 🎨 **不打扰**：主窗口可最小化，浮窗独立工作，随时点"主面板"唤回

## 📦 安装

### 下载打包好的 exe

1. 下载最新版压缩包
2. 解压到任意位置（例如桌面）
3. 双击 `任务清单.exe`
4. 第一次启动会在同目录自动生成 `sites.yaml` 和 `data/` 目录
5. 按下面"使用"章节操作

> ⚠️ **如果 360 / 火绒 / 电脑管家报毒**
>
> 这是 PyInstaller 打包程序的**普遍误报**，不是病毒。
> 请把整个文件夹添加到杀毒软件的**信任区 / 白名单**。
> 想验证可以上传 `任务清单.exe` 到 https://www.virustotal.com/ 扫描。

## 🚀 使用

### 第一次使用

1. **填 Tyche 账号密码**（如果要用 Tyche）
   - 打开设置 → 找到"Tyche"→ 点"填账号密码"
   - 填的是**打开 Tyche 网站时浏览器弹出的第一个登录框**的账号密码
   - 不是网站内部的账号密码

2. **登录各平台**
   - 主界面顶部会出现"需要登录以下站点"
   - 逐个点"登录"按钮，会弹出浏览器
     - 清华 OJ / 网络学堂：清华统一身份认证
     - 雨课堂：微信扫码
     - Tyche：Basic Auth（已填的账号密码）+ 网站内部登录
     - 数你最灵：账号密码
     - U校园：手机号 + 密码/验证码
   - 登录成功后浏览器自动关闭，作业出现

3. **开启开机自启动**（可选）
   - 设置 → 打开"开机自动启动"开关

### 日常使用

| 操作 | 位置 |
|---|---|
| 添加任务 | 主面板右上角"+ 添加任务" |
| 刷新任务 | 主面板右上角"刷新任务" |
| 重置浮窗 | 主面板右上角"重置浮窗" |
| 设置 | 主面板右上角"设置" |
| 勾选完成 | 直接点左边的复选框 |
| 删除手动任务 | 鼠标悬停在任务上，右边出现"删除"按钮 |
| 最小化主窗口 | 点右上角最小化按钮，或点浮窗的"主面板"切换 |
| 关闭程序 | 点主窗口右上角 X |

### 浮窗按钮说明

每个浮窗（红/白）右上角有三个按钮：

| 按钮 | 效果 |
|---|---|
| **主面板** | 切换主窗口的显示 / 隐藏 |
| **—** | 最小化浮窗到任务栏 |
| **×** | 关闭浮窗（不再自动弹出） |

如果不小心关掉了浮窗，可以在主面板点 **"重置浮窗"** 恢复。

### 设置

右上角"设置"分两个区块：

**🌐 网站设置**

| 操作 | 说明 |
|---|---|
| 开关 | 启用/禁用某个平台 |
| 填账号密码 | 仅 Tyche 需要，填 Basic Auth 的账号密码 |
| 清除登录 | 清除该平台的登录状态，下次需重新登录 |
| 删除 | 彻底移除该平台配置 |

> 修改后需要点右下角 **"应用"** 才生效。点"应用"前可以随时撤销改动。

**🚀 开机自启动**

一个开关，打开后每次开机并联网后自动启动。

**本软件没有服务器后端，作者收不到你的任何数据。**

- 所有数据（账号密码、登录凭证、任务记录）**只保存在你自己电脑的程序文件夹里**

1. 打开程序文件夹，所有数据都是明文 JSON 或 SQLite，可以直接用记事本查看

如果要分享给别人，**只发 `任务清单.exe` 和 `_internal/`**，不要带 `sites.yaml` 和 `data/`。

## ❓ 常见问题

**Q: 双击 exe 没反应？**

A: 检查是否有杀毒软件拦截，加入白名单后重试。也可能是 `_internal/` 文件夹丢失。

**Q: 提示"需要登录"但登录失败？**

A: 会话过期。点设置 → 清除登录 → 重新走一遍登录流程。

**Q: 红窗不显示？**

A: 只在有 24 小时内截止或已过期的任务时显示。

**Q: 抓不到某个平台的作业？**

A:
1. 该平台可能没有作业（比如体育课）
2. 该平台会话过期，去设置里重新登录
3. 网站改版了，需要更新对应的适配器

**Q: U校园只显示考试，作业和练习呢？**

A: v26.2 目前只抓考试列表。作业和练习的接口不同，会在后续版本补充。

**Q: 开机自启动不生效？**

A: 设置里关掉再打开一次。或者检查注册表：
`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` 里应该有 `HomeworkTasks`。

**Q: 浮窗被我关掉了怎么恢复？**

A: 主面板点"重置浮窗"按钮。

**Q: 数据存在哪？**

A: 全部在程序目录的 `data/` 文件夹。删掉 `data/homework.db` 会清空所有任务记录。

**Q: 会不会窃取我的隐私？**

A: **不会。这个软件没有服务器后端，作者也收不到你的任何数据。**

它本质上只是一个本地小程序：
- 没有服务器：作者没有搭任何后端接收数据，想偷也偷不到
- 全部本地存储：账号密码、登录凭证、任务记录，都只写在你自己电脑的 `data/` 里
- 不联网上传：除了访问六个平台官网拉取数据，不向任何地方发送数据

## 🗑️ 卸载

1. 设置里关闭"开机自启动"
2. 直接删除整个文件夹
3. 如果想彻底清理注册表，删除：
   `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run\HomeworkTasks`
