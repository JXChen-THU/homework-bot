## 📌 版本概览

- **v26.0**：首发版本，实现多平台作业汇总、红白浮窗、手动任务、开机自启动

---

## 🚀 v26.3 主要改进

### 1. 程序结构整理

**改动前**：主程序同时负责窗口控制、API、数据库和任务分类；站点调度代码放在项目根目录。

**改动后**：按职责拆分到 `core/`：

- `controller.py`：窗口协调和前端 API
- `database.py`：SQLite 连接和表结构
- `task_logic.py`：截止时间解析和任务分类
- `site_runner.py`：网络等待、站点配置和适配器调度
- `adapters/`：各学习平台独立的登录、抓取和数据解析

`app.py` 作为桌面程序入口，负责启动应用。

---

### 2. 网页资源拆分与复用

**改动前**：主页面的 HTML、样式和脚本放在同一文件；红色与白色浮窗有重复的交互代码。

**改动后**：

- 主页面 HTML、CSS、JavaScript 分别存放在 `web/` 下的独立文件
- 浮窗共用 `floating-common.js`，各自保留独立样式和页面结构

---

### 3. 文档归档

- 当前使用说明统一放在根目录 `README.md`
- 历史 README 归档到 `docs/archive/readme/`
- 各版本 CHANGE 日志集中放在 `docs/changelog/`，每个版本单独成文
